# Skills

用于 Codex 的个人技能集合。

| Skill | 用途 |
| --- | --- |
| [read-paper-zr](skills/read-paper-zr/SKILL.md) | 中文精读指定论文，整理背景、动机、技术与相关工作、创新、方法、实验、局限及借鉴方向；将完整笔记写入 Obsidian 的 `1-reading` 文件夹，以论文原文标题命名。 |

`read-paper-zr` 默认生成三部分笔记：**论文信息、论文简读、论文精读**。精读包含相关工作、创新、逐模块讲解、实验、局限、与模型互联网的结合及主动“提问与解惑”。方法图直接使用论文原始总框图，保留原图号；此前确认的绘图风格仅供另外明确要求重绘时使用。

## 安装与使用

在 Codex 中发送：

> 请从 https://github.com/zrliu2025-ctrl/skill 安装 `skills/read-paper-zr`。

安装后，在下一轮对话中使用：

```text
$read-paper-zr 帮我精读这篇论文：<PDF 路径、论文链接、DOI 或标题>
```

也可直接发送论文并要求阅读。默认交付简读与精读，明确只要简读时缩减；单点追问只解释相关内容。信息表提供经核对的 Zotero PDF 链接，笔记采用单一总标题、彩色引述块和清晰公式排版。

需要可用的 PDF 读取与原图提取、Zotero 条目核对及 Obsidian 笔记写入能力。默认阅读无需图片生成。优先复用已确定的 Obsidian 库；首次无法确定目标库时，会询问库位置。已有同名笔记不会被静默覆盖；用户明确要求重新阅读时，更新该论文笔记并保留有效补充与历史附件入口。
